# Qiao-MCP 0.5.1 发布说明

2026-10-13 正式发布。基于 TDQS 标准完成工具描述去重、易混淆工具选择指引及参数语义修正。

This release improves tool selection and corrects misleading call guidance while
retaining all 153 tools, existing parameter defaults and output schemas. It prioritizes
issues based on the TDQS evaluation baseline.

## Changed

- Custom temperature accepts the SDK's `[top/bottom reference, height, temperature]`
  rows and documents local directions correctly. Legacy two-value rows still pass
  through unchanged; the wrapper never invents a missing reference point.
- Self-weight guidance now uses the stage workflow. Renumbering documents its
  whole-model default; gravity/buckling settings disclose unexposed SDK defaults.
  Tendon definition, coordinates and computed losses have distinct selection guidance.
- Known overwrite operations expose accurate destructive annotations. Native
  prestress confirmation values no longer receive an unverified kN label.
- Tool descriptions omit Args only when those descriptions are fully retained in
  input schemas. Description text falls from 153,192 to **84,402 characters (44.9%)**;
  bilingual information, nested descriptions, examples and tool references remain.

## Validation and limits

1782 offline tests passed; 107 metadata/query checks passed after the final wording
changes. Ruff, Mypy, wheel/sdist consistency, installed-candidate stdio and local
`mcp-proxy@6.7.19` checks passed. The catalog retains 596 described parameters,
151 output schemas, 7 resources and 5 prompts; two tools retain MCP Image output.

TDQS 0.1.0 / spec 1.2 reports **0 errors, 39 warnings, 2 info**. Strict warning mode
exits 1. Every cost-based shadow candidate has a source-based disposition; this is
not an online grade or a calibrated semantic-model evaluation.

Engineering limits remain explicit: unverified native units, repeated-definition
rules, omitted-setting handling and backend reference migration require a dedicated
test model or reliable native exports. Older QiaoTong builds may still reject
live-load configuration/snapshot commands; the prior Rz limitation also remains.
Code/tool documentation changes do not establish engineering accuracy.
