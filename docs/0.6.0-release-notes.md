# Qiao-MCP 0.6.0

0.6.0 将完整的桥梁操作集组织为 15 个领域入口，并对齐 qtmodel 2.9.3。
它汇总 0.5.1 以来的审计修正与本地 0.5.2～0.5.9 的优化；这些中间版本无需逐个发布或安装。
原有 153 项操作及其名称调用继续保留。

## 主要变化

- **按领域选择工具。** 默认目录为 15 个工具，通过 `request.operation` 选择具体操作。
  全部 153 项操作、601 个业务参数、7 个资源和 5 个提示模板继续提供；省略、`null`、
  空列表的语义和原操作的校验、结构化返回、图像与求解进度保持兼容。
- **同步 qtmodel 2.9.3。** 锁定安装使用 2.9.3，与参考源码 `0a36bc5` 对齐。
  原有依赖范围 `>=2.6.3,!=2.9.0,<2.10` 保留，旧版能力差异仍按实际接口探测。
- **将写入绑定到当前工程。** SDK 和桌面都支持时，模型写入及提交携带工具入口检查的
  工程实例标识，后台求解线程同样受保护。嵌套调用不能改绑工程；失败或取消后清理上下文。
- **撤销时检查修订号。** 网关 `undo_model` 在桌面支持修订协议时附带模型与命令历史
  修订号；有待提交、状态不确定或无效修订数据时停止撤销。工程或修订不匹配时返回错误，
  不自动重放、不自动 Undo。旧协议继续使用现有状态检查。
- **修正建模与结果语义。** 节点和组成员使用真实回读编号；局部修改先唯一回读并保留
  适用字段；截面使用自动编号；求解和混凝土检算必须确认成功状态；提交失败说明可能已经
  发生的写入。温度、活载、检算组合和螺纹钢筋采用核对过的原生字段布局。
- **完善结果与显示。** 检算结果保留类型化字段，活载结果支持最大/最小包络；云图采用
  原生结果分量，PNG 保存到 MCP 主机。工具说明明确单位、编号空间、覆盖范围、分页和默认值。

## 从 0.5.x 升级

升级后重启 MCP 服务并刷新客户端工具目录。读取模型状态的 `tools/call` 参数为：

```json
{
  "name": "inspect_bridge",
  "arguments": {
    "request": {"operation": "get_model_status"}
  }
}
```

原调用 `name="get_model_status"`、`arguments={}` 仍然有效。
若客户端要求旧名称必须出现在发现目录中，将以下环境变量合入现有配置：

```json
{"env": {"QIAO_MCP_CATALOG_LAYOUT": "flat"}}
```

保留原 `env` 中的桥通地址等设置。完整示例及领域边界见
[调用说明](https://github.com/SorataYang/qiao-mcp/blob/v0.6.0/docs/tool-catalog.md)。

- `add_custom_temperature` 必须使用 `[参考位置, 高度, 温度]` 三列；参考位置
  `1=顶部`、`2=底部`，`orientation` 的 `1=局部 Z`、`2=局部 Y`。旧两列输入会被拒绝。
- 写入选择拒绝空字符串、空数组、布尔值和分数编号。全量操作须使用对应工具的明确参数；
  两列改号映射必须完整成对，或同时省略以使用文档所述的全模型模式。
- 本次修正不会自动重写已存在工程的数据。既有模型的质量、温度、预应力及检算定义应按
  工程意图回读核对；一键直线梁工作流的支座约束仍须按实际工程确定。

## 兼容性与已知限制

实例绑定要求 SDK 提供上下文且桌面声明 `model_instance_guard=1`；撤销修订校验还要求
`model_revision_schema=1`。初始化、打开模型和 SDK 以原始路径发送的文件命令不能携带
新实例字段，继续保留原状态检查及原生载荷。实例绑定覆盖当前工具调用，不提供事务回滚，
也不把多个客户端请求自动变成一份已审阅计划。

qtmodel 2.9.3 明确拒绝 17 个尚未开放的历史路由，涉及检算快照、规划车道完整增改等。
Qiao-MCP 保留 `API_NOT_OPEN`，被拒绝后不继续提交。仅有 SDK 方法并不能证明桌面已开放接口。
旧 SDK 的其他能力差异见
[审计矩阵](https://github.com/SorataYang/qiao-mcp/blob/v0.6.0/docs/qtmodel-code-audit.md)。

本次完成的是离线与打包验证，未新增真实工程实测。已有桥通 26.1.116.1010 的 Rz 返回、
活载 `clear_existing` 和检算快照限制仍见
[实测记录](https://github.com/SorataYang/qiao-mcp/blob/v0.6.0/docs/0.5.0-live-validation.md)，
不能由 SDK 升级推定已解决。离线测试不等于结构数值或规范验算通过。
