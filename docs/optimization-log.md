# MCP 优化记录

目标：通过官方 TDQS API 对实际 MCP 工具目录持续复评，达到综合分至少 4.5、
区分度至少 4。每轮从上一份完整报告确定改进范围，独立改动分别提交；出现可验证的
指标改善时递增补丁版本。分支为 `optimize/mcp-tools`。

每轮评估完整覆盖 153 项操作。基线至第 5 轮列出 153 个独立工具；第 6 轮起，真实
默认目录列出 15 个领域入口，每个入口保留对应操作的完整 Schema，旧名称继续兼容。
报告依据构建 wheel 的真实 stdio `tools/list`，并验证同一 wheel 的全部旧操作目录；
不存在评分专用的能力子集。目录结构变化会改变单工具统计口径，具体记录见各轮。
API 密钥不写入仓库。
托管模型未公开，未修改的工具及工具集维度也可能波动，故同时记录升降与具体改动。
