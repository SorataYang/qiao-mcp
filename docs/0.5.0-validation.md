**2.6.3 的两个既有失败保留为失败**，没有加入 xfail、改依赖下界或隐藏用例。
该版缺少 `get_load_group_names`，影响一键建桥工作流，具体失败为：

- `test_provider_calls_bind_to_qtmodel[provider::get_load_group_names::_model.get_load_group_names]`
- `test_tool_calls_bind_through_provider[tools::workflows._build_bridge::get_load_group_names]`

这些工作流需使用 2.6.4 或更新的可支持版本，仍排除 2.9.0。
依赖保持 `qtmodel>=2.6.3,!=2.9.0,<2.10` 和 `mcp[cli]>=1.29,<2`。

跳过仅表示当前 SDK 缺少相应原生能力。旧三组的 121 项为：48 项模型快照、
43 项国际/规划车道、13 项横向/显式设置、16 项 B1 查询/诊断和 1 项模型状态接口。
2.9.1 的 65 项为：48 项模型快照、13 项横向/显式设置、4 项规划车道及车道命名空间。
通用假后端测试仍验证工具行为；新增网关合同在真实 SDK 缺方法/参数时验证明确拒绝且
零写入。这类通过和跳过均不能当作旧 SDK 支持新功能的证据。

## Fixture 与工程验收边界

本仓库保存了横向的车辆/车道/工况三个定义、25 条检算快照调用、14 条国际调用和
21 条最新模型操作调用，均注明 `0687ffe` 上游导出日志来源。只解析 AST 字面量和
常量 JSON，未执行日志代码；模型操作日志中的 3 条失败注释仅记录数量，未补造操作。
Fixture 随测试提交，离线测试不依赖未跟踪的参考仓库。

真实 SDK 到假 QtServer 的 header/payload、提交次数、引用检查、状态错误和 Schema
通过，**不证明桥通工程数值正确**。以下仍待在专门的测试工程中验收，未在本轮执行：

- 横向：选择体系，定义有序且相连的车道，核对实际 ID、工况/组合和全部运营列表，
  求解后用桥通确认的完整结果名比对内力、变形、反力与单位。
- 配筋：从 UI 导出完整快照，覆盖普通截面、I/J 端及变截面组，核对提交后导出、撤销/
  重做、材料引用和 `null` 保持/`[]` 清空，再导入具名混凝土检算工况并比对结果。
- 国际：AASHTO、BS、EN1991 各走一条定义至结果链路，包含用户车辆和规划车道；
  规划车道使用模型导出/UI 核对，因其没有独立 getter，不虚构自动回读。
- BS 轴列力单位仍未获上游明确说明。当前只保留已核实的原生导出/查询值，不换算；
  工程端需确认该单位，不能从离线测试或其他规范推断为 N/kN。

以上工程步骤不能清空活动业务模型。0.5.0 的本地完成状态不包含这些工程端结果，
也不包含推送、标签和发布。
