## 质量与兼容差异

| 指标 | 已评分0.3.1 | 已发布0.5.0 | 本地0.5.1候选 |
| --- | ---: | ---: | ---: |
| 工具 | 132 | 153 | 153 |
| 描述字符总数 | 76,205 | 153,192 | 84,402 |
| 参数说明 | 0/543 | 596/596 | 596/596 |
| 输出schema | 0 | 151/153 | 151/153 |
| resources / prompts | 本轮不追溯 | 7/5 | 7/5 |

工具正文比0.5.0减少 **44.9%** 字符；不是工具数量减少，也不是线上分数变化。
对153个目录项进行了结构、默认值、注解和原始字段说明比对；对39个低分对象及21个新增对象逐项核验行为与证据。
对106个简短参数说明进一步检查后，名称、ID、分页等简单字段保留简洁写法；专项结果选择器补齐实际取值与适用种类，缩放含义未明示的地方明确交给桥通核验。

唯一输入结构扩展是 add_custom_temperature 的原生三列，旧两列 schema 仍是合法分支，原样透传。
30个工具的 destructiveHint 反映已确认的覆盖/修改；客户端可能据此更准确地提示写入。
预应力确认消息不再将原生值自行标为kN；输出仍为同一 MessageResult，解析自由文本的使用者需注意文案变化。
模型状态守卫、MCP错误通道、2个图片工具的Image返回均保留。

见[逐工具差异](glama-catalog-diff.json)、[39+21项审计](glama-improvement-audit.md)、
[选型场景与目录取舍](glama-tool-selection.md)、[39条warning处置](glama-tdqs-review.md)。
源码/SDK说明与mock载荷只证明传输契约；剩余单位、重复定义、默认覆盖、引用迁移和分析前可用性均未冒充实测通过。
