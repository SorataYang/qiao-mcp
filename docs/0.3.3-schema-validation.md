# 0.3.3 P1 verification

Verified on 2026-09-15 against MCP 1.29.0, Pydantic 2.12.5, the PyPI qtmodel
2.8.2 package, and qtmodel source revision `2316654` (also labeled 2.8.2).

## Acceptance evidence

| P1 requirement | Implementation and verification |
| --- | --- |
| Stable output contracts | All 131 non-image tools advertise `outputSchema`. Text responses retain `status` and `message`; connection diagnostics, model state and bridge workflows expose dedicated response models. Tests inspect actual MCP structured content and preserve backend state/extension fields. |
| Image compatibility | `save_model_screenshot` and `plot_analysis_result` retain MCP image content, verified through FastMCP serialization for both tools. |
| Executable input constraints | 59 parameters contain closed-set selectors; 32 contain fixed-size or nonempty arrays. Pagination and workflow dimensions have bounds. Malformed schema inputs are rejected before the model-state guard and backend dispatch. |
| Existing valid input forms | Tests exercise both node-row formats, track-positioned 2D/3D tendons, English/Chinese boundary names, case-normalized API objects and native ordered tuples. |
| `add_load_combine` guidance | Documents MDB versus CDB combinations, prerequisites, overwrite behavior, lack of automatic solving and the returned summary. Corrects native `[case_type, case_name, factor]` order and `combine_type=3` for envelopes; tests inspect dispatched arguments. |
| `apply_prestress` guidance | Documents tendon/case/group prerequisites, cable-tool alternatives, retry inspection and the need to solve before querying losses. Empty selections and invalid tension modes are rejected. |
| `create_polygon_section` guidance | Documents section-tool selection, local coordinates, topology requirements, repeat behavior and ID lookup. Closes rings without mutating caller data; its native payload is exercised with qtmodel's local geometry builder. |
| `save_model_file` guidance | Documents model-host paths, `.bfmd`, empty-path behavior, overwrite effects, backups and the returned summary. Tool annotations disclose file replacement. |
| Packaged behavior | The wheel passes the stdio initialization/catalog/structured-response/error-channel check. Its 20 Python source files match the worktree; package, lock, server and wheel versions agree on 0.3.3. |

Input schemas intentionally retain open design-code indices and backend-owned
payloads whose full domain depends on the installed QiaoTong version. Stage
numbers retain their documented special values. Polygon validation covers finite
points, distinct vertices and nonzero signed area; callers must still provide
valid nonintersecting outlines and contained holes.
